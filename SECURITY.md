# Security Policy

## Reporting

Please **do not open a public issue containing an unpatched vulnerability, credentials, or exploit details**.

For potential vulnerabilities in LG products, use LG's official security or vulnerability reporting channels. For a vulnerability in this repository, contact the maintainer privately through an appropriate GitHub private reporting mechanism if enabled.

Include the affected model, firmware version, prerequisites, reproducible impact, and a safe proof of concept when appropriate. Remove credentials, personal information, and device identifiers before sharing.

## Disclosure

We aim for coordinated disclosure and will not publish unverified claims or information that could expose third parties to unauthorized access.

## Supported versions

No software release is currently published or supported.
