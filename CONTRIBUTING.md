# Contributing

Thanks for helping make webOS research more accurate and reproducible.

- Use GitHub Issues for questions, documentation corrections, and proposed research topics.
- For device observations, start with `templates/device-report.md`.
- Clearly label **Observed**, **Reproduced**, **Hypothesis**, or **Third-party report**.
- Provide firmware version, model, date, and a safe reproduction procedure.
- Never upload credentials, tokens, personal identifiers, proprietary firmware dumps, or private vulnerability details.
- Test only devices and services for which you have authorization.
- Keep discussions constructive and cite original public sources where possible.

Contributions may be reviewed for accuracy and safety before merging.
